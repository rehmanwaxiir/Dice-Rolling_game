
# Python Dice Rolling Game

A simple dice rolling simulator built with Python. The program randomly generates a number between 1 and 6 to simulate rolling a standard six-sided die.

## Features

- Simulates rolling a six-sided die
- Generates random numbers from 1 to 6
- Allows users to roll again
- Displays the result of each roll
- Simple command-line interface

## Requirements

- Python 3
- No external libraries required

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code or a terminal.
3. Run the program:

   ```bash
   python dice_rolling_game.py
   ```

   On Windows, you can also use:

   ```bash
   py dice_rolling_game.py
   ```

4. Follow the on-screen instructions to roll the dice.

## Python Concepts Used

- Variables and data types
- `random` module
- Loops
- Conditional statements
- User input and output

## Project Type

Beginner-friendly Python command-line project for practicing random number generation and basic programming logic.
